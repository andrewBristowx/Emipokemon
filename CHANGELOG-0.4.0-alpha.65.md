# Emipokemon 0.4.0-alpha.65

## Recompensas y pase

- Las diez tiradas VIP del nivel 1 y todas las tiradas nuevas del pase se entregan como tickets físicos.

- El diario abre ahora en una Guía que explica Michicoins, tickets, pase, trabajos y casino.
