# Instalación y pruebas de Emipokemon 0.4.0-alpha.56

1. Apaga cliente y servidor y respalda el mundo, `config/emipokemon` y los datos del servidor.
2. Retira cualquier JAR anterior de Emipokemon de ambas carpetas `mods`.
3. Copia `emipokemon-0.4.0-alpha.56.jar` en cliente y servidor e inicia ambos con Java 21.
4. Conserva mundos y configuraciones; no es necesario borrarlos.
5. Completa la guía visual con una ronda individual y otra con dos jugadores.
6. Confirma que apuesta y premio se procesen una sola vez y persistan después de reiniciar.

No promociones esta compilación a estable hasta completar la validación visual real.
