# Instalación y pruebas de Emipokemon 0.4.0-alpha.57

1. Detén cliente y servidor.
2. Conserva una copia de mundos y configuraciones.
3. Sustituye únicamente el JAR anterior de Emipokemon por el JAR alpha.57.
4. Conserva los datos y configuraciones existentes; no borres carpetas del mundo.
5. Inicia el servidor con Java 21 y revisa el registro de arranque.
6. Inicia un cliente Cobbleverse con el mismo JAR.
7. Sigue `GUIA-PRUEBA-VISUAL.md` y valida también apuestas, saldo y resultados con dos jugadores.

No elimines alpha.56 hasta terminar la validación real.
