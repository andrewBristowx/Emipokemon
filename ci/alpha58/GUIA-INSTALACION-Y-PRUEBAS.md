# Instalación y pruebas de Emipokemon 0.4.0-alpha.58

1. Detén cliente y servidor.
2. Haz copia de mundos y configuraciones.
3. Sustituye únicamente el JAR anterior de Emipokemon por alpha.58 en cliente y servidor.
4. No borres datos persistentes ni configuraciones existentes.
5. Inicia el servidor con Java 21 y revisa el registro.
6. Inicia Cobbleverse con el mismo JAR.
7. Sigue `GUIA-PRUEBA-VISUAL.md`, primero con un jugador y después con dos en las mesas compartidas.

Conserva alpha.57 hasta completar la validación real.
