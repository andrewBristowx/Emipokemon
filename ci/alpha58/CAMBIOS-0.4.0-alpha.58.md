# Emipokemon 0.4.0-alpha.58

- Sustituye las pantallas planas de alpha.57 por seis composiciones ilustradas completas de 1536×1024.
- Póker incorpora tapete, cinco cartas comunitarias, cartas privadas, fichas y botonera integrada.
- Blackjack incorpora zonas separadas para crupier y jugador y controles de mano.
- Dados incorpora bandeja de tirada, dados dinámicos y tres zonas de apuesta.
- Tragamonedas incorpora carcasa, palanca, luces, carretes y control de giro.
- Cambio de fichas incorpora depósitos separados, mecanismo de intercambio y controles de compra/canje.
- Tickets incorpora una expendedora de un solo producto para el ticket normal.
- Cartas, dados, carretes, saldo, jugadores, mensajes y resultados siguen dibujándose desde datos reales.
- Los botones ilustrados se corresponden con zonas clicables que conservan las acciones autoritativas del servidor.
- No se añade el ticket premium, la Protección Emi ni productos nuevos.

Validación pendiente: revisión visual y de clics dentro del cliente Cobbleverse real.
