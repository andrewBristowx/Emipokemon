# Instalación y prueba de alpha.60

1. Detén cliente y servidor.
2. Conserva una copia de mundos y configuraciones.
3. Sustituye únicamente el JAR anterior de Emipokemon por `emipokemon-0.4.0-alpha.60.jar` en cliente y servidor.
4. Inicia con Java 21.
5. Comprueba tragamonedas, dados, blackjack, póker, cambio de fichas y máquina de tickets.

No borres los datos persistentes de Emipokemon ni las versiones estables archivadas.
