# Instalación y pruebas de Emipokemon 0.4.0-alpha.59

1. Detén cliente y servidor.
2. Conserva una copia de mundos y configuraciones.
3. Sustituye únicamente el JAR anterior de Emipokemon por alpha.59 en cliente y servidor.
4. No elimines datos persistentes ni configuraciones.
5. Inicia servidor y cliente con Java 21.
6. Sigue `GUIA-PRUEBA-ANIMACIONES.md` con un jugador y después con dos jugadores.

Conserva alpha.58 hasta completar la validación real.
