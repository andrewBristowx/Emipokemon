# Instalación de alpha.61

1. Detén cliente y servidor.
2. Conserva una copia del mundo y de `config/emipokemon`.
3. Retira únicamente el JAR anterior de Emipokemon de ambos lados.
4. Copia `emipokemon-0.4.0-alpha.61.jar` en `mods` del cliente y del servidor.
5. No elimines configuraciones ni datos persistentes.
6. Inicia primero el servidor y después el cliente Cobbleverse con Java 21.

No mezcles dos versiones del JAR en la misma carpeta `mods`.
